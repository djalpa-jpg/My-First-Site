# Mini Projects Plan

Practice projects to learn the basics before building my meal-planning app.
Each one lives in its own folder inside this repo and is linked from the homepage (`index.html`) under a "Practice projects" section.

Live site: https://djalpa-jpg.github.io/My-First-Site/

## How we work on each project

1. Create the project's folder with its own `index.html`.
2. Keep it simple: plain HTML, CSS and JavaScript in one file, no frameworks.
3. Add a link to it on the homepage, with a one-line note on which meal-planner feature it practices.
4. Explain what you changed in plain language. I'm learning, so keep explanations beginner-friendly.
5. I review, commit and push myself, then update the Status below.

## What each project does

1. **Countdown timer:** counts down days, hours and minutes to a date I pick.
2. **Tip & bill splitter:** enter a bill, tip % and number of people; shows what each person owes.
3. **Random picker:** type a list of options and click to pick one at random.
4. **Daily quote page:** shows a different quote each day from a list I write.
5. **Habit tracker:** a grid of days where I tick off a habit, and it remembers my ticks.
6. **Weather check:** type a city and see the current weather from a free weather service.
7. **Multi-page site:** expand the homepage into Home, Projects and About pages with a menu.
